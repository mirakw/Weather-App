# 🌤️ Weather App  

## 📌 Overview
The **Weather App** was created using **Bolt** to streamline development and improve efficiency.  
The **Weather App** is a simple and elegant weather forecasting application built using **Vite, React, and TypeScript**. It provides real-time weather information, including temperature, wind speed, humidity, and visibility. Users can easily toggle between **Celsius** and **Fahrenheit**.

---

## 🚀 Features  
- 🌡️ **Real-time weather updates** (Temperature, Feels-like, Wind Speed, Humidity, UV Index, etc.)  
- 🔄 **Toggle between Celsius and Fahrenheit**  
- 🌄 **Sunrise & Sunset timings**  
- 📆 **Hourly weather forecast**  
- 🎨 **Modern UI with Tailwind CSS**  
- 📍 **Location-based weather updates**  
- 🔗 **API integration with OpenWeatherMap**  
- 🌓 **Dark mode support**

## ⚙️ Installation and Setup  
### 📋 Prerequisites  
- Node.js 16+
- npm or yarn

### 📂 Step 1: Clone the repository  
```bash
git clone https://github.com/your-username/weather-app.git
cd weather-app
```

### 📦 Step 2: Install dependencies  
```bash
npm install
```

### ▶️ Step 3: Start the Development Server  
```bash
npm run dev
```
This will launch the app in your default web browser.

---

## 🚀 Deployment  
You can deploy the app using services like **Vercel, Netlify, or GitHub Pages**. For Vercel:  
```bash
vercel deploy
```

## 📜 File Descriptions  
- **src/components/**: Contains reusable UI components.
- **src/hooks/**: Custom React hooks for fetching and managing weather data.
- **src/utils/**: Utility functions for formatting and calculations.
- **public/**: Static assets.
- **tailwind.config.js**: Configuration for Tailwind CSS.
- **vite.config.ts**: Vite project settings.

## 📦 Requirements
